# Sync main và dọn workspace — Implementation Plan

> **For Hermes:** Thực hiện tuần tự, không xoá dữ liệu trước khi đã chứng minh phần đó không còn unique work.

**Goal:** Đồng bộ local `main` với `origin/main`, dọn các thay đổi staged/worktree không còn cần thiết, xác minh repo sạch để bắt đầu lesson tiếp theo.

**Architecture:** Bảo toàn an toàn dữ liệu trước: snapshot/kiểm tra diff 41 file staged, đối chiếu với `origin/main`, sau đó mới reset local `main` về remote. Dọn riêng các worktree/branch đã hoàn thành và chỉ xoá những branch không còn cần dùng.

**Tech Stack:** Git, GitHub CLI, pnpm, herdr.

## Kế hoạch thực hiện

### Bước 1 — Snapshot và đối chiếu an toàn

- Chạy `git fetch origin --prune`.
- Ghi nhận `git status`, `git diff --cached --binary`, `git diff --binary` và reflog trước khi thay đổi.
- Đối chiếu tree của staged work với `origin/main` để phân loại:
  - thay đổi đã có trên `origin/main`;
  - thay đổi local chưa có trên remote;
  - thay đổi chỉ là trạng thái staged/noise.
- Nếu có nội dung unique chưa có trên remote, dừng và báo user; không tự xoá.

### Bước 2 — Đồng bộ `main`

Chỉ khi Bước 1 xác nhận không có unique work cần giữ:

- Không merge/rebase thủ công.
- Reset local `main` về đúng `origin/main` để loại bỏ trạng thái ahead/staged cũ.
- Không push và không merge PR.

### Bước 3 — Dọn worktree và branch hoàn thành

- Kiểm tra từng worktree có thay đổi local hay process agent đang chạy không.
- Dọn worktree NES-5/Claude/Codex chỉ khi chúng đã trỏ tới commit/PR đã hoàn thành và không có thay đổi chưa lưu.
- Giữ lại worktree/branch còn phục vụ task tiếp theo hoặc có thay đổi chưa được xác nhận.
- Xoá branch local đã hoàn thành bằng `git branch -D` chỉ sau khi worktree đã được remove.
- Không đụng branch `example/nestjs-training`, `gitlab`, hoặc branch có unique work chưa được user xác nhận.

### Bước 4 — Xác minh repo sạch

Chạy:

```bash
git status --short --branch
git worktree list
git branch -vv
pnpm verify
```

Kỳ vọng:

- `main` tracking `origin/main`, không ahead/behind.
- `git status` không còn staged/unstaged/untracked.
- Chỉ còn worktree cần thiết.
- `pnpm verify` pass.

### Bước 5 — Báo trạng thái lesson tiếp theo

- Đọc roadmap/commit remote hiện tại.
- Xác định lesson tiếp theo sau L04 là L05 — DTO + Pipes + ValidationPipe.
- Không dispatch agent hoặc viết code mới nếu user chưa yêu cầu.
